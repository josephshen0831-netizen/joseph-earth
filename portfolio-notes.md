# Joseph Shen portfolio

The `portfolio.js` content object holds Media, E-Store and Events. About extends the original creator panel so its regional descriptions and original music project remain available. Keep the globe bundle and its audio/video URLs intact.

Media source files live in `media/`. The builder emits a flat release beside the self-contained globe page, rewriting relative imports so all files can be uploaded together through GitHub's picker. Use short descriptive filenames and browser-compatible H.264/AAC MP4 for future videos.

Four-hand reference implementation: Danny Elfman / Bearnabas, https://bearnabas.com/de/index.html. Hand geometry, shader sources, textures and navigation typeface are retained under `portfolio/`; the Three.js and OBJLoader source headers retain their upstream notices. The central Earth, portfolio content and JosephShen wordmark are Joseph's adaptation. Reference assets are not represented as Joseph's original artwork.

Breath Studio is presented as a prototype with email enquiries, not a fulfilled retail product. Studio Riff is a listening portfolio piece containing a third-party song excerpt, with no unlicensed commercial download.

The Media page includes two guitar performance films supplied from the Desktop: `midwest-emo-no-3.mp4` (Midwest Emo No.3) and `just-the-two-of-us.mp4` (Just the Two of Us), with individual posters and on-demand playback. The original WeChat video was replaced by these accessible sources. The Earth canvas uses its original blue-silver materials without a hue filter; portfolio accents and hands use a matching blue palette.

The JosephShen wordmark was created using the built-in image generation tool with the supplied Danny Elfman wordmark as a style reference. Prompt: “Create a finished wide website wordmark. Exact text: JosephShen. Tall psychedelic liquid molten red-orange marbled lettering with elongated sharp tips, wavering organic strokes and fine dark contour lines, dramatic 1970s experimental music poster lettering. Entire word fits on one horizontal line, recognizable letters, deep pure black background, generous black padding. No Danny Elfman text, icons or watermark.” Its final source path is `public/portfolio/media/joseph-wordmark.png`.
